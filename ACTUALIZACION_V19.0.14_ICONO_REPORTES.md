# V19.0.14 - Icono principal y selector de reportes

## Cambios
- La PWA principal de Rebanado Digital usa el nuevo icono aprobado con jamon, queso y rebanadora.
- La PWA de Pantalla de Almacen conserva su icono anterior sin cambios.
- Reportes ahora presenta los tres tipos como un selector integrado y explicativo:
  1. Vales del periodo (operacion).
  2. Productos rebanados (consumo).
  3. Merma y rendimiento (control).
- Se agrego un encabezado claro para los filtros del reporte activo.
- El boton de exportacion se identifica como `Descargar .xlsx`.
- Se corrigio el cache de la PWA principal para que el CSS nuevo no quede atrapado en una version anterior.
- Se agrego versionado a las hojas de estilo para forzar la actualizacion visual despues del despliegue.

## Base de datos
No requiere cambios de base de datos.
