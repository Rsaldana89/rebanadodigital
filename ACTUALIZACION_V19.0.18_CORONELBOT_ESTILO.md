# Rebanado Digital v19.0.18 - Indicador CORONELBOT integrado al encabezado

## Ajuste visual
- Se corrigió el bloque CSS del indicador CORONELBOT de v19.0.17, que había quedado con saltos de línea escapados y podía provocar que el navegador ignorara sus reglas.
- El indicador ahora utiliza la misma familia visual que **Atrasados**, **Tema** y **Reloj**.
- Se añadió icono contenido, nombre CORONELBOT, detalle de último contacto y una cápsula de estado **OK / ALERTA / SIN DATOS**.
- El modo oscuro usa texto claro y fondos/bordes translúcidos para conservar contraste.
- El modo claro conserva exactamente la misma geometría y cambia únicamente la paleta.
- Se añadieron ajustes responsivos para resoluciones menores.

## PWA
- Versión y caché actualizados a `19.0.18` para forzar la carga del estilo corregido en la PC/TV de Almacén.

No requiere cambios de base de datos.
