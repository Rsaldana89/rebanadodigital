# V19.0.30 · Etiquetas más claras y menú de acciones visible en tablet

## Cambios realizados

1. **Inventario / Cierre**
   - Se renombró **Rebanado para vales** a **Rebanado durante el día**.
   - Se renombró **Rebanado que queda** a **Saldo rebanado disponible** en vistas visibles.
   - Se ajustaron textos auxiliares para que el significado del inventario sea más claro.

2. **Tablet / tablero de vales**
   - Se corrigió el acomodo del botón de **tres puntos** para que permanezca a la derecha.
   - Se permitió que el menú desplegable de acciones no se recorte dentro de la tarjeta.
   - El panel de acciones emergente ahora mantiene mejor visibilidad en pantallas angostas.
